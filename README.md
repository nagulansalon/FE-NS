# FE-NS — NAGULAN Unisex Salon Frontend Web Application

Production-ready React + Vite POS Billing and Salon Management frontend application for **NAGULAN Unisex Salon** (*Hair | Skin | Beauty | Makeup* • Franchise Enquiry: **97899 61617**).

---

## 🛠️ Technology Stack
- **Framework**: React 18 + Vite
- **Styling**: Tailwind CSS (Black, charcoal and gold aesthetic)
- **Routing**: React Router v7
- **Real-Time Client**: Socket.IO Client
- **Charts**: Recharts
- **Icons**: Lucide React
- **Notifications**: React Hot Toast & Canvas Confetti
- **Exports**: SheetJS (`xlsx`) & `jspdf`

---

## 🚀 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Configure Environment Variables
Copy `.env.example` to `.env`:
```bash
cp .env.example .env
```

### 3. Start Development Server
```bash
npm run dev
```

### 4. Build for Production
```bash
npm run build
```
